DayNote 0.1.1 增加应用内更新。

- 桌面应用启动约 3 秒后检查更新，持续运行时每 6 小时再次检查。
- 发现新版本后显示版本号和更新说明，可选择“稍后”或“下载并安装”；确认前不会下载或安装。
- 设置页提供当前版本、手动检查、错误反馈和重试入口；选择稍后后，本次运行不反复提醒同一版本。
- 下载完成后验证更新签名及其绑定版本，校验不通过时拒绝安装。
- 安装前保存各日期的便签草稿，保存失败时暂停安装并保留草稿。
- 安装器覆盖升级后重新启动应用，保留原有数据目录、安装位置及桌面快捷方式。

从 0.1.0 升级：旧版没有更新功能，需要从本 Release 下载 `DayNote-0.1.1-windows-x64-setup.exe` 并手动安装一次。以后可在应用内确认更新。已有安装版使用原安装目录；旧便携版的数据迁移请参阅安装说明。

本版本没有数据库结构变更。更新前建议退出正在占用 CLI/MCP 可执行文件的外部客户端。Windows x64；尚无 Windows Authenticode 代码签名，可能出现未知发布者提示。更新包的独立签名用于应用内来源与版本校验，与 Windows 发布者签名不同。
