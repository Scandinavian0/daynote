DayNote 0.1.4 修复设置页可能沿用启动早期状态的问题。

- 每次进入设置页时重新读取当前运行状态，避免本地 MCP 服务已经启动，页面仍显示“接口未启动”或空快捷键。再次打开设置也会读取最新状态。
- 延续 0.1.3 的共享 MCP 服务：多个会话连接同一 `http://127.0.0.1:47821/mcp` 地址，无需各自启动 CLI。实际地址以设置页显示为准。
- 新增经过真实 Svelte 应用与设置入口的回归测试，覆盖启动后状态通知未更新缓存时首次进入和再次进入设置的恢复行为。

本版本没有数据库结构变更，升级保留原有数据目录与访问令牌，安装器创建桌面和开始菜单快捷方式。已配置共享 HTTP MCP 的客户端无需修改连接配置。共享服务需要 DayNote 保持运行（含托盘驻留）；选择“退出应用”后服务停止。
