DayNote 0.1.5 修复多个 MCP 客户端同时连接时可能断开的问题。

- 官方 SDK 在握手后会并行探测事件流和读取工具列表，20 个客户端可产生约 40 个同时在途请求。旧服务在 32 个活动连接占满后直接关闭新连接，导致 `UND_ERR_SOCKET`。
- 改为在接受连接之前等待容量，短时突发请求由系统的有界连接队列承接。保留 32 个活动连接的限制，以及原有认证、请求大小和超时限制。
- 新增确定性 TCP 满载回归，以及官方 SDK 的完整握手验收：每轮同时连接 20 个客户端，默认连续 10 轮，检查全部后台 GET 探测和重连。Windows Release 流程在实际安装后执行这些检查。

共享 MCP 仍由一个 DayNote 主程序提供，默认地址为 `http://127.0.0.1:47821/mcp`，无需为会话启动 CLI。已配置的客户端无需更改地址或令牌。升级保留任务数据、访问令牌、数据目录和已有开机自启设置；安装器创建桌面快捷方式。

Windows x64。更新包带 DayNote 更新器验证签名；尚无 Windows Authenticode 代码签名。此前版本曾触发卡巴斯基检测，本次修复不代表杀毒厂商已撤销历史检测。
