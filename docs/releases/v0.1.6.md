# DayNote 0.1.6

修复桌面右下角提醒透明、却仍遮挡鼠标操作的问题。

- 自动恢复已显示提醒中完全移出父视口的 WebView2 绘制子窗口，保留窗口位置、尺寸、层级与当前焦点。
- 关闭提醒后不重新弹出；队列为空或页面尚未准备好时不显示空窗。
- 修复提醒初始化、并发刷新和窗口高度更新的竞态。
- “稍后”按钮的选项换行后，提醒窗口会随内容调整高度。

安装包继续支持覆盖升级并创建桌面快捷方式，保留任务、便签、设置、令牌及共享 MCP 配置。

已知范围：本次针对在 Windows / WebView2 上实测的绘制子窗口错位。首次造成底层错位的触发事件尚未确定；恢复机制和验收边界见 [提醒窗口说明](https://github.com/Scandinavian0/daynote/blob/v0.1.6/docs/REMINDER-WINDOW.md)。
